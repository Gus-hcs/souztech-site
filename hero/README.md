# Fotos do herói

Coloque aqui de 3 a 5 fotos de obra em paisagem (canteiro, fachada, equipe),
nomeadas `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`.

- Formato: JPG, ~1920px de largura, até ~400 KB cada.
- O site troca entre elas em cross-fade. Se faltar alguma, ele só usa as que
  existirem; sem nenhuma, mostra um fundo escuro geométrico.

Depois de adicionar: `git add -A && git commit -m "fotos do herói" && git push`.
